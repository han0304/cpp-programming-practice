# Week 17 – Image Loading, Interaction, and Multimedia

This week explores image loading in Processing and introduces multimedia-related exercises, including mouse interaction, sound assets, and text-based interaction.

## Projects

### 1. Open Image from URL
**Folder:** `week17_1_open_image/`

- Load an image directly from an online URL using `loadImage()`.
- Display the image on the Processing canvas using `image()`.

**Key Concepts:** `PImage`, `loadImage()`, `image()`

### 2. Open Image from Local Files
**Folder:** `week17_2_open_image_in_files/`

- Load an image stored in the sketch's `data` folder.
- Display the local image on the canvas with specified dimensions.

**Key Concepts:** Local image resources, `PImage`, `loadImage()`, `image()`

## Key Concepts

- Loading and displaying images from online and local sources
- Working with image resources in Processing
- Introduction to mouse interaction
- Exploring audio assets and multimedia programming
- Text and String-related exercises

## Learning Outcomes

- Understand how to load and display images in Processing.
- Distinguish between online image sources and local image files.
- Become familiar with organizing external resources in a sketch's `data` folder.
- Explore multimedia programming topics through image, audio, and text-related exercises.
