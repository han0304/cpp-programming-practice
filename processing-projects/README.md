# Processing Projects

This folder contains creative coding exercises completed during my undergraduate studies.

The exercises explore visual programming, mathematical graphics, mouse interaction, image handling, and audio resources using Processing.

## Technologies

- **Processing (Java-based)**
- Mathematical expressions and coordinate transformations
- Interactive graphics and mouse events
- Image loading and rendering
- Audio resources and multimedia

## Week 16 – Creative Graphics and Interaction

This section focuses on mathematical visualization, geometric shapes, and interactive graphics.

| Exercise | Description | Key Concepts |
|---|---|---|
| Week 16-1 | Mathematical Heart Visualization | Mathematical inequalities, nested loops, graphics |
| Week 16-2 | Multiple Ellipses with Mouse Interaction | Ellipse drawing, mouse events |
| Week 16-3 | Smaller Heart | Mathematical expressions, coordinate transformation |
| Week 16-4 | Interactive Heart Drawing | User-defined functions, mouse interaction |
| Week 16-5 | Arc Drawing | Arc drawing, angle conversion |
| Week 16-6 | Multiple Arc Generation | Loops, geometric division |
| Week 16-7 | Mouse-controlled Arc | Mouse coordinates, dynamic angles |
| Week 16-8 | Big Wheel | Repeated graphics, interactive rotation |
| Week 16-9 | Lucky Big Wheel | Mouse events, rotation, velocity-based deceleration |

## Learning Outcomes

Through these exercises, I practiced:

- Translating mathematical expressions into visual representations
- Using loops and conditional statements to generate graphics
- Creating reusable functions
- Handling mouse events and user interactions
- Controlling graphical elements through coordinates and angles
- Loading and displaying images
- Exploring audio resources in Processing
