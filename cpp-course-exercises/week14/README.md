# Week 14 – Number Theory, Sorting, and Algorithmic Problem Solving

This week focuses on mathematical problem solving, number theory, sorting algorithms, array manipulation, and basic data processing using C++.

## 1. Basic Mathematical Problems

### `week14-1a.cpp`
- Checks whether an integer is a perfect square.
- Searches for an integer whose square equals the input.
- Prints the square root if found; otherwise, prints `0`.

### `week14-1b.cpp`
- Counts numbers in a given range that have no divisors between `2` and `n-1`.
- Uses nested loops to check divisibility.

### `week14-1c.cpp`
- Reads three integers and arranges them in descending order.
- Constructs a three-digit number from the sorted values and adds `1`.

## 2. Mathematical Functions and Number Theory

### `week14-2a.cpp`
- Calculates the sum of multiples of `11` from `11` to `11 * n`.
- Uses a `for` loop to accumulate the result.

### `week14-2b.cpp`
- Implements the Greatest Common Divisor (GCD) algorithm.
- Uses recursion and the Euclidean algorithm to find the GCD of two integers.

### `week14-2c.cpp`
- Reads ten values and finds the position of the smallest value.
- Calculates a speed value based on the minimum input.
- Outputs the position and calculated speed.

## 3. Arrays, Sorting, and String Processing

### `week14-3a.cpp`
- Reads ten integers and sorts them in descending order.
- Uses nested loops and swapping to rearrange array elements.

### `week14-3b.cpp`
- Reads an array of integers.
- Traverses the array in reverse order and prints odd numbers.

### `week14-3c.cpp`
- Reads up to ten characters.
- Checks each character and prints the first digit encountered.

### `week14-3d.cpp`
- Reads a numeric string.
- Inserts commas as thousands separators, processing the digits from left to right.

## 4. Time Conversion and Sequence Calculations

### `week14-4a.cpp`
- Converts a given number of seconds into hours, minutes, and seconds.
- Formats the output using two digits for each time unit.

### `week14-4b.cpp`
- Defines a function to calculate the sum of integers from `1` to `N`.
- Finds the smallest `N` (up to `100`) for which the sum exceeds a given value `K`.

### `week14-4c.cpp`
- Calculates the sum of odd numbers from `1` to `2n + 1`.
- Uses a loop to compute and display `f(n)`.

### `week14-4d.cpp`
- Performs the same odd-number summation as `week14-4c.cpp`.
- Uses a loop to calculate and display `f(n)`.

## Key Concepts

- **Mathematics:** Perfect squares, divisibility, and arithmetic sequences.
- **Number Theory:** Greatest Common Divisor (GCD) and the Euclidean algorithm.
- **Sorting:** Descending order sorting and element swapping.
- **Arrays:** Searching for minimum values and reverse traversal.
- **String Processing:** Character checking and thousands separators.
- **Functions and Recursion:** Function implementation and recursive problem solving.
- **Time Conversion:** Converting seconds into hours, minutes, and seconds.

## Learning Outcomes

Through these exercises, I practiced applying mathematical concepts to programming problems, implementing recursive algorithms, manipulating arrays, sorting data, processing strings, and organizing solutions using functions and loops.
