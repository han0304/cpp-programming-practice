# Week 01 – Basic Programming Exercises

This folder contains five introductory programming exercises completed during my undergraduate studies. The exercises cover basic drawing with Processing and fundamental input, output, and string operations in C++.

## Exercises

### Exercise 1 – Drawing an Ellipse (`week01-1.pde`)

**Description**

A simple Processing sketch that creates a 400 × 400 canvas and draws a red ellipse without an outline.

**Key Concepts**
- Setting canvas dimensions with `size()`
- Setting fill colors with `fill()`
- Removing outlines with `noStroke()`
- Drawing shapes with `ellipse()`

### Exercise 2 – Character and Integer Input (`week01-2.cpp`)

**Description**

A C++ program that reads a character and an integer from the user, then displays the entered values.

**Key Concepts**
- Declaring `char` and `int` variables
- Reading input with `scanf()`
- Displaying output with `printf()`
- Using format specifiers `%c` and `%d`

### Exercise 3 – String Input and Output (`week01-3.cpp`)

**Description**

A C++ program that reads a string from the user and displays the entered text.

**Key Concepts**
- Declaring character arrays
- Reading strings with `scanf()`
- Using `%s` as a format specifier
- Displaying string values with `printf()`

### Exercise 4 – Counting a Specific Digit (`week01-4.cpp`)

**Description**

A C++ program that reads a string and counts how many times the digit `2` appears in it.

**Key Concepts**
- String handling with character arrays
- Calculating string length with `strlen()`
- Iterating through a string using a `for` loop
- Conditional statements with `if`

### Exercise 5 – Counting Digits Across Multiple Inputs (`week01-5.cpp`)

**Description**

An extension of Exercise 4. The program repeatedly reads strings until the end of input (EOF), counts the occurrences of the digit `2` in each string, and calculates the total count.

**Key Concepts**
- Repeated input using a `while` loop
- Reading input until EOF
- String traversal and character comparison
- Accumulating results with a total variable

## Learning Outcomes

Through these exercises, I practiced:
- Basic programming syntax and structure
- Input and output operations
- Character and string manipulation
- Loops and conditional statements
- Basic data processing and counting logic
