# Week 11 – Array Manipulation and String Mapping

This week focuses on solving LeetCode problems involving array manipulation and string comparison. The exercises introduce finding the two largest values in an array, updating array elements, and checking whether two strings follow the same character mapping pattern.

## Exercises

### 1. LeetCode 1046 – Last Stone Weight (`week11-1.cpp`)

Implements a function that repeatedly finds the two heaviest stones in an array. The selected values are removed from the array, and if their weights are different, the remaining weight is stored back in the array. The process continues until no stones or only one stone remains.

**Key Concepts:**
- Array traversal
- Finding maximum values
- Array element updates
- Loops and conditional statements
- Implementing problem-solving logic

### 2. LeetCode 205 – Isomorphic Strings (`week11-2.cpp`)

Implements a function to determine whether two strings are isomorphic. It checks whether each character in one string can be consistently mapped to a character in the other string, using two lookup tables to ensure the mapping works in both directions.

**Key Concepts:**
- C-style strings
- String length with `strlen()`
- Character mapping
- Lookup tables using arrays
- Two-way mapping validation

## Learning Outcomes

- Practice traversing arrays to find and compare maximum values.
- Understand how to update array elements during an algorithm.
- Apply loops and conditional statements to solve programming problems.
- Use lookup tables to track character relationships.
- Understand one-to-one character mapping when comparing strings.
