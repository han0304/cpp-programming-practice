# Week 17 – Array Searching and Character Comparison

This week focuses on searching for characters in an array and comparing character values using conditional statements.

## 1. Character Searching

### `week17-1.cpp`
- Implements LeetCode 744: Find Smallest Letter Greater Than Target.
- Searches through an array of characters to find the smallest letter greater than the target.
- Returns the first letter in the array if no letter is greater than the target.
- Uses a loop and conditional statements to compare characters.

## Key Concepts

- **Character Comparison:** Comparing characters using their ASCII values.
- **Array Traversal:** Iterating through an array to examine each element.
- **Linear Search:** Searching for a character that satisfies a given condition.
- **Conditional Statements:** Using `if` statements to determine the appropriate result.

## Learning Outcomes

Through this exercise, I practiced character comparison, array traversal, and linear search techniques to solve a programming problem.
