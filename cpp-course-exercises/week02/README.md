# Week 02 – Integer Operations and Absolute Difference

This folder contains five C++ exercises focused on integer operations and calculating the absolute difference between two input values.

The exercises gradually introduce different approaches to subtraction, conditional statements, larger integer types, and standard input/output streams.

## Exercises

### Exercise 1 – Basic Subtraction (`week02-1.cpp`)

**Description**

A C++ program that repeatedly reads two integers and calculates the difference between the second integer and the first integer.

**Key Concepts**
- Declaring integer variables with `int`
- Reading multiple values using `scanf()`
- Performing subtraction
- Repeating input until EOF

### Exercise 2 – Absolute Difference (`week02-2.cpp`)

**Description**

An extension of Exercise 1. The program calculates the absolute difference between two integers using conditional statements.

**Key Concepts**
- Conditional statements with `if`
- Comparing two integer values
- Calculating the absolute difference
- Repeated input processing

### Exercise 3 – Using Long Long Integers (`week02-3.cpp`)

**Description**

This exercise extends the absolute difference calculation by using `long long int` to support larger integer values.

**Key Concepts**
- Using `long long int` for larger integers
- Reading and displaying long long values with `%lld`
- Checking the sign of a subtraction result
- Conditional statements

### Exercise 4 – Standard Input and Output Streams (`week02-4.cpp`)

**Description**

A C++ program that calculates the absolute difference between two integers using `cin` and `cout` instead of `scanf()` and `printf()`.

**Key Concepts**
- Including the `<iostream>` library
- Reading input with `std::cin`
- Displaying output with `std::cout`
- Using `std::endl`
- Working with `long long int`

### Exercise 5 – Using Namespace std (`week02-5.cpp`)

**Description**

This exercise builds on Exercise 4 by using `using namespace std` to simplify the syntax of standard input and output operations.

**Key Concepts**
- Using namespace declarations
- Simplifying `std::cin` and `std::cout`
- Performing absolute difference calculations
- Repeated input processing

## Learning Outcomes

Through these exercises, I practiced:
- Basic arithmetic operations
- Comparing integer values
- Using conditional statements to calculate absolute differences
- Understanding the difference between `int` and `long long int`
- Using both C-style and C++-style input/output operations
- Processing multiple inputs until EOF
