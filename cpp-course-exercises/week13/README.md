# Week 13 – Programming Fundamentals and Problem Solving

This week contains a collection of programming exercises covering matrix operations, mathematical calculations, number manipulation, conditional statements, and array processing. The exercises focus on applying fundamental C programming concepts to solve different types of problems.

## Exercises

### 1. LeetCode 1572 – Matrix Diagonal Sum (`week13-1.cpp`)

Calculates the sum of the primary and secondary diagonals of a square matrix. The center element is subtracted once when the matrix has an odd dimension to avoid double counting.

**Key Concepts:**
- Two-dimensional arrays
- Matrix traversal
- Primary and secondary diagonals
- Array indexing

### 2. Basic Functions and Number Operations (`week13-2a.cpp` – `week13-2e.cpp`)

- **`week13-2a.cpp`** – Defines a function to return the absolute value of an integer.
- **`week13-2b.cpp`** – Reverses the digits of an integer using arithmetic operations.
- **`week13-2c.cpp`** – Reads a sequence of integers and prints the square of each value.
- **`week13-2d.cpp`** – Converts a four-digit binary string into its decimal value.
- **`week13-2e.cpp`** – Reads integers until a zero is entered, then counts how many times a specified number appears in the stored values.

**Key Concepts:**
- Function definition and function calls
- Integer arithmetic
- Loops and arrays
- Binary-to-decimal conversion
- Counting occurrences

### 3. Mathematical and Conditional Problems (`week13-3a.cpp` – `week13-3e.cpp`)

- **`week13-3a.cpp`** – Extracts the thousands digit of an integer.
- **`week13-3b.cpp`** – Calculates the sum of squares from 1 to a given integer.
- **`week13-3c.cpp`** – Calculates the sum of integers divisible by 3 within a given range.
- **`week13-3d.cpp`** – Determines the quadrant of a point based on the signs of its coordinates.
- **`week13-3e.cpp`** – Calculates the sum of all positive divisors of an integer.

**Key Concepts:**
- Mathematical calculations
- Modulo operator
- Conditional statements
- Iteration and accumulation
- Divisibility and factors

### 4. Arrays, Time, and Practical Calculations (`week13-4a.cpp` – `week13-4e.cpp`)

- **`week13-4a.cpp`** – Checks a year using a leap-year condition.
- **`week13-4b.cpp`** – Reads ten integers and prints them in reverse order.
- **`week13-4c.cpp`** – Calculates a speed value based on a given input.
- **`week13-4d.cpp`** – Calculates the number of cups needed to hold a given amount of water, rounding up when necessary.
- **`week13-4e.cpp`** – Calculates the area of a rectangle using the absolute differences between two pairs of coordinates.

**Key Concepts:**
- Conditional statements
- Array traversal
- Reverse iteration
- Integer division and remainder
- Practical mathematical calculations

## Learning Outcomes

- Apply functions, loops, and conditional statements to solve programming problems.
- Perform mathematical operations using integers and the modulo operator.
- Understand binary-to-decimal conversion and number manipulation.
- Process one-dimensional and two-dimensional arrays.
- Apply programming logic to practical calculation problems.
