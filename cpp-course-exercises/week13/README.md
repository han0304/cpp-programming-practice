# Week 13 – Matrix Diagonal Sum

This week focuses on two-dimensional arrays and matrix traversal through LeetCode 1572.

## Exercises

### 1. LeetCode 1572 – Matrix Diagonal Sum (`week13-1.cpp`)

Implements a function that calculates the sum of the primary diagonal and secondary diagonal of a square matrix. When the matrix has an odd dimension, the center element is subtracted once to avoid counting it twice.

**Key Concepts:**
- Two-dimensional arrays
- Matrix traversal
- Primary and secondary diagonals
- Array indexing
- Conditional statements
- Sum calculation

## Learning Outcomes

- Understand how to access elements in a two-dimensional matrix.
- Identify and traverse the primary and secondary diagonals.
- Use array indexing to calculate diagonal sums.
- Handle the overlapping center element in odd-sized square matrices.
